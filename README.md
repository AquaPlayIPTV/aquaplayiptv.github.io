# aquaplayiptv.github.io

Public pages for AquaPlay IPTV. No app code lives here.

- `index.html` — the page a phone opens from the QR code on a TV to send it a playlist
- `help.html` — AquaPlay's settings explained, opened from the app
- `privacy.html` — the privacy policy
- `samsung.html` — how to install AquaPlay on a Samsung TV with Apps2Samsung, and its `images/`
- `report.html` — the page a phone opens from a crash report's QR code (Settings → Advanced → Crash report). The report is in the address after the `#`, which a browser never sends, so this page is the same for everyone and receives nothing
- `premium.json` — a small switch the app reads to know which TVs Premium is on for
