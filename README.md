# aquaplayiptv.github.io

Public pages for AquaPlay IPTV. No app code lives here.

- `index.html` — the page a phone opens from the QR code on a TV to send it a playlist
- `privacy.html` — the privacy policy
- `samsung.html` — how to install AquaPlay on a Samsung TV with Apps2Samsung, and its `images/`

Served at https://aquaplayiptv.github.io/
